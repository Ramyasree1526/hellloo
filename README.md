# Personal Portfolio

This is a simple, single-page personal portfolio website featuring a dark hero section, an about me section, skills showcase, **education details**, projects gallery, and a contact form.

## Technologies Used

*   **Frontend**: HTML, Tailwind CSS (via CDN), JavaScript
*   **Icons**: Font Awesome (via CDN)

## Features

*   Responsive design
*   Smooth scrolling navigation
*   Dark theme with a prominent hero section
*   Showcase for skills, education, and projects
*   Functional (client-side) contact form

## How to Run Locally

Since this is a purely frontend project, you can open `index.html` directly in your web browser.

1.  **Save the files**: Save `index.html` and `README.md` into a directory.
2.  **Open `index.html`**: Navigate to the directory and double-click `index.html`.

That's it! Your portfolio should now be visible in your browser.

### Customization

*   **Edit Content**: Update `[Your Name]`, descriptions, education details, and project details in `index.html`.
*   **Images**: Replace the placeholder image URLs with your own project images and profile picture. You can use the provided image URLs or find new ones.
*   **Skills**: Add or remove skills and their respective Font Awesome icons.
*   **Contact Form**: Currently, the contact form only displays a success message. For a real application, you would integrate a backend service (e.g., Node.js with Express, Python with Flask/FastAPI, or a service like Formspree) to handle email submissions.
